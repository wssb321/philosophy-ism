# 哲学主义

一个完全在浏览器中运行的中文哲学思想测评站。它包含五套中立测评、主义百科、随机名言、六维立场模拟器、本地历史和高清结果图导出。

## 本地预览

项目没有构建步骤，也没有运行时依赖。在项目目录启动任意静态文件服务器：

```powershell
python -m http.server 4173
```

随后访问 `http://localhost:4173/`。不要直接双击 HTML 文件，因为浏览器会限制 ES 模块读取。

## 自动校验

```powershell
npm test
```

测试覆盖题库数量与平衡、计分与匹配、版本化本地存储、历史安全渲染、模拟器、图片导出，以及全站本地链接和锚点。

## 目录

- `mindset/`、`philosophy/`、`metaphysics/`、`politics/`、`ethics/`：五套测评与题库定义
- `assets/js/`：计分、会话、存储、结果、模拟器和历史等公共模块
- `assets/css/`：全站样式与响应式规则
- `tests/`：Node.js 原生测试
- `docs/`：需求、批准规格、实施计划、视觉概念和验收记录

## 隐私与降级

回答、进度和历史只保存在当前浏览器的 `localStorage`，不会发送到服务器。Chart.js 与 html2canvas 通过 CDN 加载；即使 CDN 不可用，完整文字结果仍可阅读，图片导出按钮也会给出打印或系统截图建议。

## 静态部署

将项目根目录完整上传到任意静态托管服务即可。入口文件是 `index.html`，无需服务端路由、数据库或环境变量。若站点部署在子目录，应确保托管服务保留现有相对路径结构。
