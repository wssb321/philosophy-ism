# 全站一站式视觉系统 QA 台账

日期：2026-10-18

范围：首页、主义百科、随机名言、立场模拟器、历史记录、关于网站、五套测评、即时结果、历史结果与 PNG 导出。
验证矩阵：1536×1024、1024×768、768×1024、320×720；浅色与深色；共 64 个核心页面状态，另单独完成即时结果与导出路径。

## 一致性检查

| 项目 | 发现与证据 | 修复 | 最终状态 |
|---|---|---|---|
| 导航与壳层 | 各页面原先标题区、导航密度和按钮状态不一致 | 统一粘性页头、六项主导航、主题与菜单按钮、页首引言和页脚 | 通过；移动菜单与当前页状态可见 |
| 字体层级 | 工具页和结果页的标题尺度偏小，缺少编辑感 | 建立宋体展示层、无衬线正文层、眉题、编号和阅读宽度 | 通过；320px 下无截断 |
| 色彩与表面 | 首页参考图使用暖纸色、墨色、蓝灰和赭色，旧内页表面不统一 | 全站复用纸张、墨色、蓝灰、赭色、边线与状态令牌 | 通过；浅色与深色均检查 |
| 分隔线与容器 | 旧页面依赖卡片圆角，和参考图的横向编辑布局不一致 | 改为细分隔线、开放容器、编号区块和稳定内容宽度 | 通过；桌面和平板层级一致 |
| 水墨资产 | 首页已有水墨主视觉，内页缺少延续 | 名言页复用水墨背景与坐标圆，其他页面通过纸纹、细线和坐标语汇呼应 | 通过；未增加无关装饰资源 |
| 百科阅读 | 长词条在双栏和窄屏之间缺少明确节奏 | 加入编号、分类、正文区、通俗解释、粘性搜索筛选和单栏断点 | 通过；搜索“荒诞主义”仅返回一项 |
| 测评交互 | 五套测评视觉分散，答案语义曾出现标签和输入框重复单选角色 | 统一进度、题号、整行答案、键盘提示、操作区和五种强调色；保留原生单选语义 | 通过；完整跑通 30 题、上一题、恢复与结果 |
| 模拟器与历史 | 工具反馈与档案层级不足 | 增加输入／映射双栏、当前最接近流派、档案编号、时间、分数、查看与删除层级 | 通过；滑块使首选从伊壁鸠鲁主义变为人文主义；8 条本地记录可读 |
| 结果报告 | 即时与历史结果样式不统一，导出在现代 `color-mix()` 下失败 | 统一画像摘要、雷达图、维度、通俗解释、相近倾向、免责声明与操作区；导出使用固定 RGB 纸张色 | 通过；深色页面成功显示“图片已保存。” |
| 移动端 | 测评装饰圆曾造成横向滚动；长文本存在潜在溢出 | 限制装饰溢出、加入 `overflow-wrap`、44px 触控目标和分层移动断点 | 通过；矩阵中 `scrollWidth <= innerWidth` |
| 深色模式 | 水墨图、答案状态、结果纸张与按钮需保持对比 | 设置图像亮度、主题表面、选中状态和固定浅色导出模式 | 通过；矩阵控制台 0 error / 0 warning |
| 页面语义 | 随机名言页矩阵检查发现缺少唯一 H1 | 将动态名言设为页面 H1，并保留换句动画与排版 | 通过；结构测试覆盖唯一页面主标题 |
| 交互生命周期 | 整分支自审发现重新测试后旧数字键监听器可能残留 | 完成测试和重新挂载前调用 `destroy()` 注销旧监听器 | 通过；回归测试覆盖清理接口 |
| 部署脚本 | Vercel Analytics 的 `/_vercel/insights/script.js` 被本地链接审计误判为文件缺失 | 将 `/_vercel/` 识别为部署平台虚拟端点，其他本地链接仍严格检查 | 通过；链接审计无误报 |

## 交互证据

- 百科：搜索与分类共同过滤；新增人生哲学词条具有稳定锚点和四段通俗解释。
- 名言：点击“换一句”后名言、作者与来源同步变化。
- 模拟器：六条坐标实时更新雷达图、最高匹配与接近度列表；图表不可用时保留文字结果。
- 测评：心智认知 30 题完整完成；数字键、上一题、恢复、结果生成和本地历史均保留。
- 历史：历史结果可重建同一报告；单条删除与清空确认由安全 DOM 和单元测试覆盖。
- 导出：暗色界面中生成固定浅色 PNG；失败、并发和免责声明保护均有自动测试。

## 最终结论

自动测试、链接审计、四视口双主题矩阵与关键交互均通过。无未解决 P0、P1、P2 问题。
