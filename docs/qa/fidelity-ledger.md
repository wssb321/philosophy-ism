# 视觉概念对照记录

对照素材：`docs/design/homepage-concept.png` 与 `docs/qa/implementation-homepage.png`

## 一致点

1. 保留暖白纸张底色、深墨文字、蓝色主操作与赭色强调的综合色板。
2. 使用宋体风格展示标题、无衬线字体承载界面信息，形成编辑出版物般的层级。
3. 桌面端保持品牌、六项导航与主题开关的单行顶栏结构。
4. 首屏延续左侧大标题与行动按钮、右侧思想坐标视觉的双栏构图。
5. 五套测试在首屏下方形成连续编号带，并保留各自题数和预计用时。
6. “不是告诉你该相信什么”宣言仍作为首页第二视觉重心，并以留白强化节奏。

## 有意调整

- 概念中的水墨山水改为纯 CSS 坐标圆、轴线与光晕，避免首屏依赖大图资源，同时保留“思想坐标”的核心隐喻。
- 测试入口删去装饰插图，换取更清楚的题量信息和更稳定的 320 像素响应式表现。
- 宣言区减少背景装饰，让实际产品内容与可读性优先于概念稿中的氛围层。

结论：信息架构、色彩、字体、主视觉隐喻和页面节奏与批准概念一致；差异集中在装饰图像的轻量化处理，不影响品牌方向或核心交互。
